📖 多开复盘 — 使用指南

1. 搜索股票
顶部搜索框输入股票代码或名称，按 Enter 直接跳转到第一条结果。

2. 大盘指数
首页大盘栏展示上证/深证/创业板实时行情（红涨绿跌），点击任一指数进入详情分析页。

3. K 线图操作
进入个股页后，在 K 线图或技术指标图上任意位置点击，会出现蓝色竖线标记当天，并弹出「点位分析」面板。
两张图的缩放和拖动自动同步，切换指标时竖线不会丢失。

4. 五窗口预测（核心功能）
点击某天后，系统用该天之前 1060 根 K 线训练 12 项技术指标的权重，分别在 T+1 / T+3 / T+5 / T+10 / T+30 五个时间窗口上计算胜率并归一化。
每个时间窗口独立预测，点击上方 Tab 切换查看不同周期的加权评分。
例：想看 5 天后走势 → 点「T+5日」Tab → 该窗口用各指标在 T+5 的胜率赋权

5. 加权评分含义
📊 看涨/看跌：各指标按该窗口胜率加权投票的结果
置信度：加权看多/看空占比（差距 < 5% 时显示震荡）
✅/❌：加权预测 vs 该窗口实际走势的验证结果

6. 颜色约定（全站统一）
🔴 红色 = 上涨 / 看涨 / 阳线
🟢 绿色 = 下跌 / 看跌 / 阴线
K 线蜡烛、指标数值、综合评分均遵循此规则。

7. 技术指标
共 12 项：成交量 → MA → MACD → KDJ → RSI → BOLL → OBV → WR → CCI → BIAS → PSY → VR
点击指标名称可查看原理公式和使用法则。

8. 注意事项
• 数据来源腾讯财经接口，仅供个人学习研究，不构成投资建议
• 训练数据仅使用选中日期之前的历史数据，无未来信息泄露
• 每只股票独立训练权重，不跨股
